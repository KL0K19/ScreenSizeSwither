ScreenSizeSwitch.cs is a C# script designed for quickly switching display resolutions and screen modes (fullscreen, windowed, borderless). It allows users to toggle screen dimensions and aspect ratios using presets or hotkeys without opening Windows display settings or GPU control panels.

ScreenSizeSwitch.cs — это C# скрипт для быстрого переключения разрешения дисплея и режима отображения (полноэкранный, оконный, без рамок). Он позволяет менять параметры экрана и соотношение сторон через готовые пресеты или горячие клавиши без необходимости заходить в системные настройки Windows или панели управления видеокарт.

ScreenSizeSwitch.cs — це C# скрипт для швидкого перемикання роздільної здатності дисплея та режиму відображення (повноекранний, віконний, без рамок). Він дозволяє змінювати параметри екрана та співвідношення сторін за допомогою готових пресетів або гарячих клавіш без необхідності відкривати системні налаштування Windows чи панель керування відеокарти.
